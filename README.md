# room-expense-bill-splitting-system
A Python project for managing shared room expenses and calculating roommate balances.
Room Expense & Bill Splitting System

Project Overview

The Room Expense & Bill Splitting System is a software project designed to help roommates manage shared expenses and calculate how much each person owes.

The application will allow users to record expenses, identify who paid, select the roommates sharing each expense, and calculate the final balance for each person.

Project Objectives

* Manage roommate information.
* Record shared expenses.
* Divide expenses fairly among selected roommates.
* Calculate how much each roommate owes or should receive.
* Store expense records for future reference.

Planned Technologies

* Programming Language: Python
* Database: SQLite
* User Interface: Tkinter (planned)

Planned Features

1. Add and manage roommates.
2. Record expenses and identify the payer.
3. Split expenses equally among selected roommates.
4. Calculate individual balances.
5. View previously recorded expenses.
6. Store data locally using SQLite.

Development Status

Status: Planning and initial setup.

The project requirements and initial system design have been prepared. Implementation and testing will take place progressively during development.

Project Scope

The initial version will focus on equal expense splitting, roommate management, expense records, and balance calculations. Additional features may be considered after the basic version is working.
